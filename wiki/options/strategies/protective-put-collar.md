# Protective Put / Collar（保护性 Put / 领口）

**本目录**：[期权总览](../index.md) · [知识综合总结](../knowledge.md) · [备兑 Call](covered-call.md) · [Long Call / Long Put](long-call-long-put.md)

**状态**：已分析（公开的模拟盘报告不含这两个策略，因为要配合真实持股；私下可用 `/collar-screen` 试，见第 9 节）
**最后更新**：2026-10-25
**一句话**：持股的同时买一张 Put，给下跌买一个确定的下限（Protective Put）；再卖一张更高行权价的 Call 把保费补回来，就变成上下都封住的 Collar——**代价是美国应税账户里有一条会咬人的持有期规则**。

> 来源口径：标 **（A）** 的来自 [projectoption 教程](../sources/projectoption-beginners-guide.md)（视频本身未独立核实）；**（核算）** 是本页自己算的，**（推导）** 是没有来源背书的推理或业界通行做法。**本页不是税务建议**，涉及 IRS 的部分务必自己核实。不构成投资建议。

---

## 1. 构成与盈亏

### Protective Put

| 腿 | 方向 | 说明 |
|----|------|------|
| 股票 | 持有 100 股 | 组合的主体 |
| Long Put | 买入 1 张 | 行权价通常低于现价，就是你的"下限价" |

| 项 | 公式 |
|---|---|
| 下限（保底卖出价） | Put 行权价 |
| 最大亏损 | （股票成本 − Put 行权价 + 每股权利金）× 100 |
| 盈亏平衡 | 股票成本 + 每股权利金 |
| 最大收益 | 不封顶（上涨只被权利金拖慢） |
| 成本 | 权利金，纯支出 |

### Collar（领口）

| 腿 | 方向 | 说明 |
|----|------|------|
| 股票 | 持有 100 股 | |
| Long Put | 买入 1 张 | 下限 |
| Short Call | 卖出 1 张 | 上限，收的钱补贴 Put 的成本 |

| 项 | 公式 |
|---|---|
| 下限 | Put 行权价 |
| 上限 | Call 行权价 |
| 净期权成本 | Put 付出 − Call 收到（做到约 0 就叫 zero-cost collar） |
| 结果 | 股价被锁在 [下限, 上限] 的区间里 |

### 案例（A，美光）

| 项目 | Protective Put | Collar |
|---|---|---|
| 股票成本 / 现价 | $300 买入 / 现价 $975 | 同 |
| 买 Put | 2027 年到期 $800 Put，花 $5,000 | $800 Put，每股 $50（= $5,000） |
| 卖 Call | — | $1,320 Call，每股 $50（= $5,000） |
| 净期权成本 | $5,000 | **约 $0** |
| 锁定区间 | 下限 $800，上涨不封顶 | 下限 $800，上限 $1,320 |
| 锁定利润（至少） | **$45,000**（核算，($800 − $300) × 100 − $5,000） | **$50,000**（核算，($800 − $300) × 100 − $0） |

> **口径提醒（核算）**：A 对 Collar 说的"$50"是**每股**，一张合约是 $5,000。保护性 Put 那边直接给了总额 $5,000，两处换算一致。

### 这两个策略真正在做的事

**不是"降低风险"，是"把一段不确定换成确定"**（推导）：

- Protective Put：付 $5,000 换掉 $800 以下的全部下跌。相当于**给 $80,000 的头寸买了一份保费 6.25% 的保险**（核算，$5,000 ÷ $80,000）
- Collar：不花钱换掉 $800 以下的下跌，代价是放弃 $1,320 以上的全部上涨。美光案例里现价 $975，**上限只有 35% 的空间，下限有 18% 的缓冲**（核算）

## 2. 什么时候用 / 不用

**适用**

- **浮盈很大、不想卖出**：A 的案例就是这个场景——成本 $300、现价 $975，不想缴税或不想离场，但也不想还回去（推导）
- **有明确的事件风险窗口**：财报、诉讼、FDA 结果前买 Put 过桥（推导）
- **持股满一年之后**：A 明确说持满 1 年再用保护性 Put（见第 5 节税务那条）
- **Collar 适合"愿意在某个价位卖出"的持股**：上限就是你的卖出价，和[备兑 Call](covered-call.md) 的逻辑一样（推导）
- **集中持仓又不能分散时**（员工股票、低成本基仓）：Collar 是把风险区间压窄的少数办法（推导）

**不适用**

- **持股不满 1 年的美国应税账户**：持有期会被重置（A），税率代价可能远大于保护的价值
- **只是"觉得市场有点贵"**：长期滚动买 Put 的保费会持续侵蚀收益（推导）
- **预期大涨**：Collar 的上限会把最赚的那一段切掉
- **权利金很贵时（高 IV）**：保险最贵的时候往往也是最想买的时候；A 的 IV 对比（AMD $50.45 vs 微软 $20.45）说明同样条件下保费能差一倍以上
- **想用它替代止损**：Put 是有成本、有到期日的保险，不是免费的纪律（推导）

## 3. 选合约规则

### Put 的行权价：下限定在哪

| 选择 | 保费 | 含义 |
|---|---|---|
| 接近现价（ATM） | 最贵 | 几乎不让亏，但保费会吃掉大部分收益 |
| 虚值 10%~20%（A 的案例约 18%） | 中 | 自留一段损失，换便宜保费 |
| 深虚值 | 便宜 | 只防崩盘，日常波动全自己扛 |

**选法（推导）**：先问"我能接受自己承担多少下跌"，那个数字就是 Put 的行权价，而不是反过来按保费挑。

### 到期日

- A 的案例用的是**远月**（2027 年到期），对应"长期持有 + 长期保护"
- 远月 Put 单价高但**按天摊的保费更低**；近月便宜但要不停滚动，累计更贵（推导）
- **事件保护**：到期日要盖过事件，且留几天余量（推导）

### Collar 的 Call 行权价

- 先定 Put（下限），再找一个权利金大致相等的 Call 来定上限——这就是 zero-cost collar 的做法（推导）
- **上限必须是你真的愿意卖的价**，否则到时候又要花钱买回来（推导，同[备兑 Call](covered-call.md) 第 3 节）
- 区间越窄，这个组合越接近"已经卖掉股票"（推导）

### 流动性（A）

两条腿都要过：OI 数千以上、买卖价差 < 期权价格的 5%；只用限价单。远月合约流动性通常更差，价差更宽（推导）。

## 4. Greeks 与组合效果

| | Protective Put | Collar |
|---|---|---|
| Delta | 正，小于 1.0（Put 的负 Delta 抵一部分） | 正，更小 |
| Theta | **负**（买方付时间价值） | 接近中性（两腿抵消） |
| Vega | 正（IV 上升时 Put 变贵，组合受益） | 接近中性 |
| Gamma | 正 | 混合 |

**两个有用的视角（推导）**：

1. **Protective Put = 持股 + 保险 ≈ Long Call**：持 100 股加一张 Put，盈亏形状和买一张同行权价的 Call 基本一致（合成等价）。所以"浮盈很大、买 Put 保护"约等于"卖掉股票、改买 Call"——区别在税务和分红
2. **Collar = 备兑 Call + 保险**，也可以读成"用放弃的上涨买下跌保护"。Theta 和 Vega 都被压到接近中性，意味着**这个组合几乎不再受时间和波动率影响**，只剩区间内的方向

## 5. 风险与常见错误

| # | 风险 | 来源 | 要点 |
|---|---|---|---|
| 1 | **持有期被重置（美国 IRS）** | A | 持股不满 1 年就买保护性 Put，**持有期清零**，将来卖出享受不到长期资本利得税率。A 的建议：持满 1 年后再用。**这是本页最该记住的一条** |
| 2 | **保费的累计侵蚀** | 推导 | 滚动买 Put 是持续成本；案例的 6.25% 保费（核算）要靠股票涨更多才补得回 |
| 3 | **Collar 的上限代价** | 核算 | 美光案例上限 $1,320，现价 $975 之上只留 35%；真涨过去就全是放弃的收益 |
| 4 | **把 Collar 当"不花钱"** | 推导 | 零成本指的是现金流，不是机会成本 |
| 5 | **Call 腿被提前指派（除息前）** | 推导 | 实值 Call 的买方可能在除息日前行权拿分红，股票被提前叫走，Put 腿就裸露了。A 只讲了"外涵接近 0 才需留意" |
| 6 | **只保护了一条腿的到期日** | 推导 | Put 到期后保护消失，很多人忘了续；Collar 两腿到期日必须一致 |
| 7 | **远月合约的流动性** | A | 价差宽，入场即损失 |
| 8 | **以为 Put 能防跳空归零** | 推导 | 能防，但下限之下的损失早已发生——下限之上那一段（案例是成本 $300 到 $800）仍然是自己的风险 |
| 9 | **IV 高时买保险** | A | 同条件保费能差一倍以上（AMD/微软对比） |
| 10 | **税务的其他部分全是空白** | A、C | A 只讲了持有期重置；Collar 在美国税法下还可能触发其他认定，五个来源都没覆盖，自己查 |

## 6. 管理与退出

- **Put 的三个结局（推导）**：① 股价涨——Put 归零，保费是沉没成本，继续或停止保护都行；② 股价跌破行权价——卖出 Put 获利（通常比行权划算，因为行权放弃外涵价值，A 的机制）或行权把股票按下限卖掉；③ 快到期——决定续不续
- **什么时候该把保护拿掉（推导）**：事件过去、或股价涨到让"下限"已经远低于成本价时，保护的边际价值很低
- **Collar 的调整（推导）**：股价贴近上限时，可以把 Call 往上往后展（Roll up and out），但通常要净付钱——判断标准同[备兑 Call](covered-call.md) 第 6 节：只在"按新的上限我仍然愿意继续持有并再收一次钱"时做
- **别把保护滚成赌局**：Put 腿越买越虚值、越买越近月，保护就名存实亡（推导）
- **来源缺口**：A 只给了结构和案例，展期、续保、拆解完全没讲，本节全是推导

## 7. 与相邻策略的对比

| 策略 | 相同点 | 不同点 |
|---|---|---|
| **[备兑 Call](covered-call.md)** | 都是持股 + 期权 | 备兑只卖上涨收权利金，**不提供下跌保护**；Collar = 备兑 Call + 用权利金买 Put |
| **[Long Put](long-call-long-put.md)（单独）** | 都买 Put | 单独 Long Put 是做空方向；这里是给持股上保险。同一张合约，用途相反 |
| **直接卖掉股票** | 都能规避下跌 | 卖出会实现资本利得（案例里浮盈 $67,500），Collar 不实现但把区间锁住。**选择往往是税务驱动的**（推导） |
| **止损单** | 都想限制下跌 | 止损单免费但会在跳空里失效、也会被洗出去；Put 有成本但到期前确定有效（推导） |
| **[垂直 Put 贷方价差](bull-put-credit-spread.md)** | 都涉及 Put | 那是卖方收权利金；这是买方付保费。方向相反 |

**一句话（推导）**：想不花钱减少下跌风险，唯一的办法是放弃上涨（Collar）；想保留上涨，就得付保费（Protective Put）；两者都不想，那就只能接受风险或者卖股票。

## 8. 来源与核对

**来源**

- [projectoption 新手完整指南](../sources/projectoption-beginners-guide.md)（A）：美光的 Protective Put 和 Collar 案例、持有期重置的税务陷阱、IV 对保费的影响、流动性与限价单、行权 vs 平仓、提前指派机制
- 汇总：[知识综合总结](../knowledge.md)第二部分持股保护组合、第五部分风险清单第 4 条

**本页自己算的（核算）**

- Protective Put 锁定利润至少 $45,000（($800 − $300) × 100 − $5,000）
- Collar 锁定利润 $50,000（净期权成本约 $0）
- 保费率 6.25%（$5,000 ÷ $80,000 的下限名义额）
- 下限缓冲 18%、上限空间 35%（相对现价 $975）
- "每股 $50 = 每张 $5,000"的口径换算

**未核实 / 缺口**

1. **A 没给 IV、也没说是哪一年的行情**，案例只能当结构示例；美光的股价是视频录制时的快照
2. **税务只有一条**：持有期重置（A）。Collar 在美国税法下的其他认定、IRA/401(k)/应税账户差异，五个来源都没覆盖。**本页不是税务建议**
3. **展期、续保、拆解**：来源完全没讲，第 6 节是推导
4. **除息前的提前指派**（第 5 节第 5 条）是推导，A 只讲了外涵价值接近 0 的情形
5. **合成等价**（Protective Put ≈ Long Call、Collar ≈ 备兑 Call + Put）是推导，来源没有这个表述
6. **没有任何长期成本数据**：滚动买 Put 的年化保费侵蚀有多大，来源没讲，本页也没有样本（推导）

## 9. 公开的模拟盘报告不含

[模拟盘报告](../paper-trading.md)只记两个卖方策略（`bull_put_spread`、`cash_secured_put`）。Protective Put 和 Collar **都要配合真实持股**，和[备兑 Call](covered-call.md) 一样不在公开报告里，所以公开页上没有本仓库自己的样本；私下的模拟盘工具见文末「模拟盘工具」一节。

自己私下要验证的话，要记的和纯期权策略完全不同（推导）：

- **股票成本价、建立保护时的现价、下限、上限**四个价格都要记，否则事后分不清保护值不值
- **保费占头寸的比例**，以及按年摊算的累计保费——这是唯一能判断"保险买贵了没有"的口径
- **和"什么都不做"对比**：保护策略的正确问题不是"赚没赚钱"，而是"**比单纯持股多赚还是少赚，以及少赚换来了多少确定性**"
- **是否触发持有期重置**，以及由此产生的税率差异（第 5 节第 1 条）
- Collar 还要记**被叫走时的机会成本**，同备兑 Call

> 不构成投资建议，也不构成税务建议。本页不写个人持仓、成交价或账户信息。
