# 现金担保 Put（Cash-Secured Put）

**本目录**：[期权总览](../index.md) · [知识综合总结](../knowledge.md) · [模拟盘报告](../paper-trading.md) · [垂直 Put 贷方价差](bull-put-credit-spread.md) · [备兑 Call](covered-call.md) · [Wheel](wheel.md)

**状态**：已分析（模拟盘尚无已结算样本，见第 9 节）
**最后更新**：2026-10-24
**一句话**：对自己愿意长期持有的优质股，用低于现价的行权价卖出 Put 并备足全额现金——没跌破就白收权利金，跌破了就按折扣价接股；最大风险是接到股票后继续下跌，理论亏损为行权价 × 100。

> 来源口径：标 **A / B / C** 的数字来自 [projectoption 教程](../sources/projectoption-beginners-guide.md)、[Invest with Henry](../sources/henry-sell-put-income.md)、[天哥复利之道](../sources/tiange-sell-put-retirement.md) 三个来源的转述，视频本身未独立核实；标 **（核算）** 的是本页自己算的；标 **（推导）** 的是来源里没有、从机制推出来或属于业界通行做法的内容。不构成投资建议。

---

## 1. 构成与盈亏

| 腿 | 方向 | 说明 |
|----|------|------|
| Short Put | 卖出 1 张 | 虚值（行权价 < 现价），到期日通常 28~45 天 |
| 现金 | 冻结 | 行权价 × 100 × 张数，全程不动用 |

**“现金担保”四个字就是这个策略的全部约束**：没有这笔现金，同一张合约叫 Naked Put，亏损由保证金和追缴来约束，风险性质完全不同。

### 公式

| 项 | 公式 |
|---|---|
| 最大收益 | 净权利金 × 100 × 张数（股价到期在行权价之上） |
| 最大亏损 | （行权价 − 净权利金）× 100 × 张数（股价归零） |
| 盈亏平衡 | 行权价 − 净权利金 |
| 占用资金 | 行权价 × 100 × 张数 |
| 单笔回报率 | 净权利金 ÷ 行权价 |
| 简单年化 | 单笔回报率 × 365 ÷ 持有天数（不复利） |

**收益是封顶的，亏损不是。** 股价涨 50% 和涨 1%，卖方拿到的都是同一笔权利金；跌 50% 则是实打实的浮亏。这条不对称是整个策略的性格。

### 两个案例

**案例一：AAPL 月度（B）**

| 项目 | 数字 |
|---|---|
| 股价 / 行权价 | 约 $170 / $160（虚值，缓冲约 5.9%） |
| 到期 | 28 天 |
| 买卖价差 | Bid $1.76 / Ask $1.82，中间价 $1.79 |
| 权利金 | $179 |
| Delta / 近似胜率 | 0.21 / 79% |
| 占用现金 | $16,000 |
| 盈亏平衡 | $158.21（距现价 6.9%） |
| 单笔回报率 | 1.12%（核算） |
| 简单年化 | 约 14.6%（核算，1.12% × 365 ÷ 28） |
| 最大亏损（归零） | $15,821 |

**案例二：AMD 季度（A）**

| 项目 | 数字 |
|---|---|
| 股价 / 行权价 | $473 / $400（缓冲 15.4%，核算） |
| 到期 | 55 天 |
| 权利金 | $1,115 |
| 占用现金 | $40,000 |
| 盈亏平衡 | $388.85（距现价 17.8%，核算） |
| 单笔回报率 | 2.79%（核算） |
| 简单年化 | 约 18.5%（核算） |
| 最大亏损（归零） | $38,885 |

**被指派后长什么样（核算，以 AMD 为例）**：到期股价 $350，短腿深度实值，按 $400 接下 100 股，实际成本 $388.85（已扣权利金），账面浮亏 $3,885——是一次权利金的 3.5 倍。继续跌到 $300，浮亏 $8,885，是 8 倍。**“79% 胜率”说的是不被指派的频率，不是亏损幅度**（B 的口径，知识总结第七部分第 7 条已标）。

### 真实占用比表面数字高

A 提到卖 AMD $450 Put 只收 $2,500，券商初始冻结约 $13,115。那是保证金账户的口径。**现金担保的定义就是放弃这个杠杆**：按行权价 × 100 备全额，等于主动把券商可能的追缴风险换成了资金效率的损失。这是一个明确的交换，不是缺点。

## 2. 什么时候用 / 不用

**适用**

- **标的**：自己真心看好、愿意长期持有的优质龙头（B 举 Apple、Amazon、Google、Palantir；C 分保守 SPY / 稳健 AAPL、QQQ / 激进 TSLA、NVDA、PLTR 三档）。黄金法则是 C 的 **Wish to Own**：按下卖出前问“如果明天跌 20%、被迫持有 5 年 10 年，我是开心还是焦虑”——开心才卖
- **IV 环境**：中高 IV 更划算，权利金就是卖方的报酬，IV 低的时候同样的 Delta 收不到钱（推导）
- **走势**：回调后在底部走平、或触及强支撑（B 例：Apple 在 $169 附近止跌走平）
- **账户**：现金充足、本来就计划在更低价位建仓的账户。这个策略最自然的用法不是“做收益”，而是“把限价买单变成收费的限价买单”（推导）

**不适用**

- **不想持有的标的**：五个来源里风险排名第一（B、C）。暴跌被指派后被迫长期持有不想要的资产；真退市则本金归零，Wheel 也救不了
- **现金不足**：只要需要靠保证金顶上，性质就变成 Naked Put
- **已知事件窗口**：财报、FDA、并购投票这类日期跨在到期日之前时，权利金贵是因为风险真的大，跳空可以直接穿透缓冲（推导；来源未展开）
- **低 IV 的横盘大盘股**：收益不够补偿尾部风险（推导）
- **账户的全部资金都压在一个标的**：C 对激进高 Beta 个股的要求是仓位占总资金 10%~15%，只作收益增强

## 3. 选合约规则

### 到期日

| 类型 | 天数 | 来源态度 |
|---|---|---|
| 周度 | 约 7 天 | 单次权利金少，适合高频练手（B） |
| **月度** | 约 28 天 | **B 强烈推荐**长期被动投资者；收益稳定、省时省力 |
| 标准月度（第三个周五） | 剩余 30~45 天 | A 建议新手优先 |
| 实盘短周期 | 14 天 | C 的演示用，单期回报更高但要盯得更勤 |

**为什么是 30~45 天**：时间价值的衰减不是线性的，越临近到期衰减越快，但最后一两周 Gamma 也最大——同样的股价波动对持仓的冲击成倍放大。30~45 天是“衰减已经够快、Gamma 还没失控”的区间（推导）。

### 行权价与 Delta

- B 推荐 **Delta 约 0.20~0.21**，对应约 79%~80% 的不被指派概率
- C 的说法是“九折挂单”：股价 $100 卖 $90 的 Put
- **取舍很直接**：行权价越低、Delta 越低 → 越安全、权利金越少。平值（Delta 约 0.46）权利金最高，但被指派概率接近一半（B 把“贪高权利金选平值”列为常见错误）
- Delta 的三重含义要分清（A）：① 股价每变 $1 期权价变多少；② 近似到期成为实值的概率；③ 等效股数。卖 1 张 Delta 0.20 的 Put，方向暴露约等于持有 20 股（推导）

### 流动性门槛（A）

- **未平仓合约数（OI）**：数千甚至数万以上
- **买卖价差**：黄金法则是小于期权价格的 **5%**（$10 的期权价差 < $0.50；$1 的期权价差 < $0.05）
- **反例**：SOXX 部分合约买卖价差达 $2.30，入场即巨亏
- **只用限价单**，挂中间价或更优；严禁市价单

### 一个可以直接用的开仓检查单（推导）

1. 这只股票我愿意持有 5 年吗？
2. 备足 行权价 × 100 的现金了吗？
3. 这笔占总资金多少？（单一标的建议 ≤ 10%~15%）
4. 到期日之前有财报或已知事件吗？
5. OI 够吗？买卖价差 ÷ 期权价 < 5% 吗？
6. 单笔回报率、简单年化、盈亏平衡价，三个数字都算出来了吗？
7. 被指派的那天我具体做什么？（接股 / 平仓 / 展期，提前写好）

## 4. Greeks 与收益来源

| 希腊字母 | 卖 Put 的方向 | 含义 |
|---|---|---|
| **Delta** | 正（+0.20 的短腿约 +20） | 看涨。股价涨，持仓赚 |
| **Theta** | **正** | 每过一天都在赚；这是主要收益来源 |
| **Vega** | 负 | IV 上升持仓浮亏，IV 下降浮盈 |
| **Gamma** | **负** | 股价越往不利方向走，Delta 越大，亏损加速。这是最容易被忽视的一项 |

**负 Gamma 的实际含义（推导）**：开仓时 Delta 0.20，股价跌到行权价附近时 Delta 会涨到 0.5 以上，再跌就接近 1.0。也就是说**股价越跌，这笔持仓越像“已经持有 100 股”**——风险暴露自己长大，不需要你加仓。所以仓位必须按“万一全部被指派”来算，不是按开仓时的 Delta 算。

**收益从哪来**：C 的说法是**波动率风险溢价**——“买股票的人是猎人赌方向，卖 Put 的人是保险公司收保费”。D 的历史科普给了同一个结论的来源：期权本质是保险，买方付费买确定性，卖方收费承担不确定性。隐含波动率长期略高于已实现波动率，这个差额就是卖方的报酬（推导：来源没有用 IV 与 RV 之差来表述）。

**双重收益的真相（C + 核算）**：C 把“闲置现金在券商货币基金约 3.95% 年化”和“权利金年化 15%”相加得到 18.95%。算术没错，但口径有问题——这笔现金是担保金，被指派时要拿去买股，且该模型假设每月权利金稳定、完全没算被指派后的浮亏。当作上限看，不是预期值。

## 5. 风险与常见错误

| # | 风险 | 来源 | 要点 |
|---|---|---|---|
| 1 | **对劣质股卖 Put** | B、C | 头号风险。被指派后被迫长期持有不想要的资产；退市则本金归零 |
| 2 | **贪高权利金选平值** | B | Delta 0.46 被指派概率近 50%，和“打折买股”的初衷背道而驰 |
| 3 | 被最大亏损数字吓退 | B | $15,821 是股价归零的极端假设；对优质龙头过度盯它会不敢开仓 |
| 4 | 没想好到期后怎么办 | B | 其实简单：虚值继续卖 Put，实值接股卖备兑 Call |
| 5 | 保证金追缴 | A | 只发生在非全额担保的账户；全额现金担保就是为了消掉这一条 |
| 6 | 流动性与滑点 | A | 不活跃合约入场即损失 |
| 7 | 连赚三次之后的那一笔 | E | 典型规律：赚了膨胀 → 膨胀就加仓 → 加仓就踩坑 |
| 8 | 贪婪 | C | C 认为最大风险是贪婪而不是股价下跌 |
| 9 | **跳空穿透缓冲**（推导） | — | 5.9% 的缓冲挡不住一次 −20% 的财报跳空；缓冲是概率上的，不是物理上的 |
| 10 | **机会成本**（推导） | — | $16,000 锁 28 天换 $179。同期标的本身涨 10% 则少赚 $1,600 以上；这个策略在强势上涨行情里是跑输的 |
| 12 | **提前指派** | A | 只要实值期权里还有可观外涵价值，理性买方不会提前行权（放弃外涵价值不合算）。卖方只需在“外涵接近 0 且临近到期”时留意 |
| 13 | **税务** | A、C | A 只讲了保护性 Put 会重置持股持有期；**现金担保 Put 在 IRA / 401(k) / 应税账户的差异，五个来源都没讲**（C 明说没讲），实际操作前自己查 |

**最常见的认知错误（推导）**：把“胜率 79%”当成“期望为正”。两者是两回事——79% 的时候赚 $179，21% 的时候可能亏 $179 以上的数倍。这个策略能长期为正，靠的是波动率风险溢价和标的本身向上的长期漂移，**不是靠胜率高**。所以标的选择（第 2 节）的权重远高于参数优化。

## 6. 管理与退出

### 三个结局

| 到期状态 | 做法 |
|---|---|
| 虚值（OTM） | 期权归零，权利金全收，下一个交易日重新开仓，循环（B） |
| 实值（ITM）且想接股 | 被指派后按行权价接下标的股票，相当于折价买到想要的股票，之后可以等反弹或转备兑 Call（B、C） |
| 实值但不想接股 | 到期前平仓，或展期（见下） |

### 提前止盈（推导；来源未讲）

业界通行做法是**赚到权利金的 50%~75% 就平掉**。理由是时间价值衰减的后半段单位时间收益最差，而 Gamma 风险在后半段最大——用剩下 25%~50% 的收益去换最后几天的尾部风险不划算。代价是手续费翻倍和需要更频繁地重新开仓。五个来源都是“持有到期”的口径，这一条属于自己补的。

### 展期（Roll，推导；C 明说没讲）

股价跌向行权价、不想接股时：

- **Roll out（往后展）**：平掉当前合约，卖出更远到期日的同行权价合约。通常能净收权利金（时间价值更多），等于“用时间换空间”
- **Roll down and out（往下往后展）**：同时降低行权价。安全边际更大，但净权利金可能变成净支出
- **什么时候不要展**：如果展期的唯一理由是“不想认亏”，那是在给一个错的判断加仓。原则（推导）：只在**仍然愿意按新行权价持有这只股票**时展期，否则直接平仓认亏

### 被指派之后：[Wheel](wheel.md)（B、C）

1. 现金 Sell Put —— 赚权利金 + 现金利息（“给下跌卖保险，赚恐慌”）
2. 被指派后持股，卖备兑 Call —— 行权价设在成本价之上（“给暴涨卖彩票，赚贪婪”）
3. 股票被行权卖走，变回现金，回到第 1 步

横盘时可以持续卖 Call，收权利金和分红。**Wheel 的前提依然是第 2 节的标的质量**——对垃圾股做 Wheel 只是把亏损拉长。

### 退出规则要开仓前写好（推导）

Delta 0.20 的合约，八成以上的日子里什么都不用做；真正决定长期结果的是剩下那两成日子怎么应对。所以止盈线、展期条件、认亏条件应该在开仓当天写进交易日志，而不是在股价跌破行权价的那个下午临时决定。

## 7. 与相邻策略的对比

| 策略 | 相同点 | 不同点 |
|---|---|---|
| **Naked Put** | 合约完全一样 | 不备全额现金，靠保证金。有追缴风险，可用杠杆。合约相同、风险管理不同 |
| **[垂直 Put 贷方价差](bull-put-credit-spread.md)** | 同样卖虚值 Put 收权利金，同样中性偏多 | 多一条更低行权价的长腿。占用资金从“行权价 × 100”降到“宽度 − 权利金”（MU 案例是 $84,000 对 $885），但权利金更少、亏损触发更快，而且到期落在两腿之间时仍然要接股。见[知识综合总结](../knowledge.md)的该节 |
| **[备兑 Call](covered-call.md)** | 都是卖方、都收权利金、收益都封顶 | 持股 + 卖 Call。盈亏曲线和现金担保 Put 几乎是同一条（合成等价），区别在起点是现金还是股票 |
| **[Wheel](wheel.md)** | 第一步就是现金担保 Put | 是一个包含它的循环流程，不是另一个策略 |
| **直接买 100 股** | 都看多 | 买股票没有到期日、上涨不封顶、吃全额分红；卖 Put 有权利金垫底但放弃了上涨 |
| **挂限价买单** | 都是“等更低的价格买入” | 卖 Put 为等待本身收费，代价是必须在到期日之前等到，且股价暴跌时也一样要买 |
| **[Protective Put / Collar](protective-put-collar.md)** | 都和 Put 有关 | 方向相反：那是买 Put 付费买保险，这是卖 Put 收费当保险公司 |

**合成等价的实用含义（推导）**：现金担保 Put 的盈亏曲线和备兑 Call 基本重合。所以“Sell Put 比买股票安全”这句话只在“行权价低于现价”这个范围内成立——安全来自折扣和权利金，不来自策略本身。

## 9. 用模拟盘验证

验证需要什么（推导，方法论沿用 E）：

- **样本量**：报告里的阈值是 30 笔；低于这个数的胜率不要解读
- **要记的字段**：标的、行权价、Delta、到期天数、净权利金、占用资金、到期结果、被指派后的后续处置、下一交易日开盘跳空
- **真正要回答的问题**不是“胜率多少”，而是“被指派的那些笔，平均亏多少，有没有吃掉虚值那些笔的全部收益”
- **开仓价偏差**：报告已经在跟踪“下一交易日开盘相对快照价的平均绝对跳空”。真实世界无法按中间价快照成交，这个数字越大，模拟结果越乐观

> 不构成投资建议。本页不写个人持仓、成交价或账户信息。
