# 垂直 Call 贷方价差（Bear Call Credit Spread）

**本目录**：[期权总览](../index.md) · [知识综合总结](../knowledge.md) · [垂直 Put 贷方价差](bull-put-credit-spread.md) · [垂直 Call 借方价差](bull-call-debit-spread.md) · [备兑 Call](covered-call.md) · [Naked Call](naked-call.md) · [Bear Put 借方价差](bear-put-debit-spread.md)

**状态**：已分析（来源偏少，仍有待核项，见第 8 节；模拟盘工具 `/bearcall-sim` 见第 9 节，公开报告仍不含，也还没有能下结论的样本）
**最后更新**：2026-10-30
**一句话**：卖一个较低行权价的 Call、同时买一个更高行权价的同到期 Call，净收权利金；看跌到横盘都赢，最大亏损被长腿锁成固定数字，代价是**单笔收益远小于亏损、需要约 70%~80% 的胜率才打平**。

> **口径警告**：本页公式与机制转述自 OIC（optionseducation.org）、Fidelity、FINRA、IRS 和 Wealthsimple 的公开资料，**数字例子全部是虚构标的 ZZZQ**（现价 100），不是真实行情，也不是模拟盘记录。标 **（核算）** 的是本页自己算的，**（推导）** 是没有来源背书的推理或业界通行做法，**待核** 是没有从来源确认的事实。不构成投资建议。

## 1. 构成与盈亏

| 腿 | 方向 | 说明 |
|----|------|------|
| 短腿 Short Call | 卖出 | 行权价较低（通常略高于现价），是收钱的那条腿，也是风险来源 |
| 长腿 Long Call | 买入 | 行权价更高、同一到期日，是花钱的那条腿，把"涨上天"的风险截断 |

净收权利金，所以叫**贷方**（credit）；看跌到横盘赢，所以叫 **Bear**。

它是[垂直 Put 贷方价差](bull-put-credit-spread.md)在 Call 一侧的镜像：同样是"收钱、赢面大、赔率差"，只是赌的方向相反——这里赌的是**不会涨过短腿**。

### 公式

| 项 | 公式 |
|---|---|
| 宽度（width） | 长腿行权价 − 短腿行权价 |
| 净权利金 | 短腿收到 − 长腿付出 |
| 最大收益 | 净权利金 × 100 × 张数（到期股价 ≤ 短腿行权价，两腿都作废） |
| 最大亏损 | （宽度 − 净权利金）× 100 × 张数（到期股价 ≥ 长腿行权价） |
| 盈亏平衡 | 短腿行权价 + 净权利金 |
| 占用资金 | 监管底线按最大亏损算：FINRA 规则下，价差里短腿的保证金取「常规要求」与「最大潜在亏损」中较小者，长腿须全额付款，卖出所得可抵用（来源 FINRA Regulatory Notice 12-44）；各券商可自行加严，实际数字以券商为准 |
| **理论盈亏平衡胜率** | 最大亏损 ÷（最大亏损 + 最大收益）= 1 − 净权利金 ÷ 宽度 |

### 案例（虚构 ZZZQ）

| 项目 | 数字 |
|---|---|
| 现价 | $100 |
| 到期 | 35 天（假设） |
| 卖出 | $105 Call，收 $2.10 |
| 买入 | $110 Call，付 $0.90 |
| 净权利金 | $1.20（每张 $120） |
| 宽度 | $5 |
| 最大收益 | $120 |
| 最大亏损 | $380 |
| 盈亏平衡 | $106.20 |
| 占用资金 | $380 |
| 单笔回报率 | 31.6% |
| 理论盈亏平衡胜率 | 76% |

**核算**：

- 净权利金 = 2.10 − 0.90 = 1.20
- 最大收益 = 1.20 × 100 = **$120**
- 最大亏损 = (5 − 1.20) × 100 = 3.80 × 100 = **$380**
- 盈亏平衡 = 105 + 1.20 = **$106.20**（比现价高 6.2%）
- 占用资金 = 最大亏损 = **$380**
- 回报率 = 120 ÷ 380 = 31.6%
- 盈亏平衡胜率 = 380 ÷ (380 + 120) = 380 ÷ 500 = **76%**；用另一个公式验算：1 − 1.20 ÷ 5 = 1 − 0.24 = 0.76，一致

**到期三种结果（核算）**：

| 到期股价 | 结果 | 盈亏 |
|---|---|---|
| ≤ $105 | 两腿都作废 | +$120（满额） |
| $105~$110 | 短腿实值被指派、长腿作废 | 每股亏 (股价 − 105)，再加回 $1.20；$106.20 恰好打平；被指派后账户里会多出一个空头股票头寸（Fidelity） |
| ≥ $110 | 两腿都实值，互相对冲 | −$380（满额） |

例：到期 $108，短腿内在价值 3.00，净结果 = 1.20 − 3.00 = −1.80，即 −$180。

### 收益率的错觉

31.6% 的回报率看着高，是因为分母（占用资金）被长腿压小了。而同一个长腿把权利金/宽度压到 24%，盈亏平衡胜率因此高达 76%。这和 Put 贷方价差是同一个性格：**换来的是"最大损失可控"，不是"期望值更高"**（推导）。

## 2. 什么时候用 / 不用

**适用**

- **看跌到横盘，不是暴跌**：OIC 的定位是中性偏空，预期股价持平或回落即可赢；它不是做空的替代品，赢面来自"不涨"，不来自"大跌"
- **有明确上方压力位**：把短腿放在压力位之上，让压力位替你挡一层（推导；压力位不是保证）
- **IV 偏高**：权利金是卖方的全部报酬，IV 高时同样的虚值程度能收到更多，权利金/宽度比更容易接近宽度的 25% 以上（推导）。教程另提示：IV 上升对这类卖方价差不利，因为被卖出的那条腿涨得更多（Wealthsimple）
- **不想承担 Naked Call 的无限风险**：这是[Naked Call](naked-call.md)加一条保险腿后的有限风险版本

**不适用**

- **长期看空**：OIC 提到，要精确判断从短期反弹转为长期下跌的时点很难；这个策略只管到期日前的这一段（转述 OIC）
- **强势上涨的标的、动量股**：股价只需要冲过长腿一次，就吃满额亏损（推导）
- **财报、并购传闻、FDA 等事件窗口**：跳空可以一步穿过两条腿（推导）
- **临近除息日且短腿已经实值**：见第 5 节的指派风险
- **流动性一般的标的**：两条腿都要吃买卖价差（推导）

## 3. 选合约规则

以下数字没有监管或教育机构给出硬性标准（OIC、Fidelity、tastylive 的 bear call 页面都未给 Delta/到期日的具体数字），属业界通行做法，均为（推导）；仅个别点有 tastylive 的自述佐证，已标出：

- **到期日**：约 30~45 天的月度合约是常见选择，在时间价值衰减和反应时间之间折中；周度合约衰减最快但 Gamma 风险最大。tastylive 自述偏好约 45 天（仅搜索摘要，未读到原页面，**待核**）。「21 天止盈/出场」的说法我没有找到任何来源，本页不采用
- **短腿 Delta**：约 0.15~0.30（推导，无来源）。Delta 近似"到期被价内的概率"，不等于不亏钱的概率。tastylive 的研究摘要提到过 16 delta、30 delta 的短腿（多为 strangle 研究，不是垂直价差，仅摘要）；Delta 越高，收益与波动越大、胜率越低
- **宽度**：宽度直接决定最大亏损；宽度越大，"部分亏损"缓冲区越宽，全有全无的性质越弱
- **权利金/宽度**：先定一个下限，低于它就不做——这个比例直接决定盈亏平衡胜率（例：24% → 76%；20% → 80%；33% → 约 67%）（核算）。20% 是本页的经验下限（推导）；tastylive 的摘要提到他们倾向让权利金约为宽度的三分之一（仅搜索摘要，**待核**）
- **流动性**：两条腿的未平仓合约数都要有数千级别，买卖价差小于期权价的 5%（沿用 [projectoption 教程](../sources/projectoption-beginners-guide.md) 对流动性的口径）
- **下单**：用整个价差的组合限价单（net credit），不要分腿下单，以免中途露出单腿（推导）

## 4. Greeks 与收益来源

| 希腊字母 | 整个价差的方向 | 说明 |
|---|---|---|
| Delta | 负，但比裸卖 Call 小得多 | 长腿的正 Delta 抵掉一部分 |
| **Theta** | **正** | 主要收益来源；OIC 提到，比单卖 Call 的衰减收益小，因为长腿也在衰减 |
| Vega | 理论上很小，略负 | 两条腿的 Vega 方向相反，大部分抵消（转述 OIC）；但 Wealthsimple 指出 IV 上升仍对该策略不利 |
| Gamma | 负，在两个行权价之间最猛 | 股价进入两腿区间时，盈亏变化最快 |

**收益来源**是时间价值衰减加上"股价不涨"。长腿相当于用一部分权利金买走尾部风险，代价是收益上限被砍、盈亏平衡胜率被推高（推导）。

## 5. 风险与常见错误

| # | 风险 | 要点 |
|---|---|---|
| 1 | **赔率差** | 例子里最大亏损 $380 对最大收益 $120，一笔满额亏损约等于 3.2 笔满额盈利（核算：380 ÷ 120 = 3.17） |
| 2 | **做空的逆风** | 美股长期倾向上涨，看跌的一方要面对基础方向的逆风（推导；不是定论） |
| 3 | **早期指派（短腿）** | 见下一节 |
| 4 | **到期指派不确定** | OIC 提示：可能到到期后的周一才知道短腿是否被指派；股价在短腿附近时最麻烦，可能多出一个意外的股票头寸并暴露于周末跳空 |
| 5 | **跳空** | 财报或消息一步穿过两条腿，直接锁定满额亏损 |
| 6 | **窄宽度 = 全有全无** | 两腿距离太近时，部分亏损区间几乎不存在 |
| 7 | **长腿流动性** | 更虚值、更冷门，买卖价差更大 |
| 8 | **连续获利后加仓** | 70%+ 胜率天然制造连胜，容易放大仓位 |
| 9 | **税务** | 非专业经营者卖出期权，到期作废的权利金按短期资本利得处理（IRS Pub. 550）；对冲性质的持仓可能被认定为 straddle，亏损抵扣会被递延。价差是否适用、被指派后的处理，见第 8 节，请咨询税务人士 |

### 短腿的早期指派与除息日

只有**短腿**可能在到期前被指派；长腿由你自己控制，没有被指派的风险（转述 Wealthsimple）。

- **高危场景**：短腿已经实值，且距离下一个除息日很近。Call 的买方若想拿到股息，必须在除息日**之前**行权变成股东。当股息金额大于该 Call 剩余的外在价值（extrinsic value）时，行权才划算，所以指派最常发生在外在价值接近零的深度实值 Call 上；Fidelity 说最常发生在除息日前一天（转述 OIC、Wealthsimple、Fidelity）
- **虚构例子（核算）**：ZZZQ 涨到 $112，短腿 $105 Call 内在价值 7.00；若盘中报价 7.10，则外在价值 0.10。假设下一次股息 $0.50 > 0.10，买方行权拿股息就划算，指派概率很高。此时价差已经接近满额亏损（宽度 5，净权利金 1.20，亏 3.80）
- **被指派之后**：你被迫以 $105 卖出 100 股（等于变成空头股票）。补券有两条路：在市场买入股票，或在长腿实值时行权长腿。OIC 提到，用长腿补时可能因通知延迟而多留一个交易日的空头；Fidelity 补充，买股票的交割晚一天，可能产生利息和佣金
- **应对**（转述 Fidelity）：想排除指派风险，就把整个价差平掉，或只买回短腿、保留长腿；长腿没有被指派的问题，但单留长腿等于变成一笔单买 Call，需要重新评估
- **保证金风险**：被指派会生成股票头寸，账户权益不足时可能触发追加保证金（转述 Wealthsimple、Fidelity）
- **Hard-to-borrow（难借券）**：若被指派后一时无法用长腿补券、需要借券卖空，难借券标的的借券费率可能很高，甚至借不到券；这属于券商规则：我只在 IG 帮助页的搜索摘要里看到「被指派的短 Call 形成的空头股票同样要付难借券费」，IBKR、Schwab 页面访问被拒（403），未读到全文，**仍待核**。对事件频繁、做空拥挤的标的应格外谨慎（推导）
- **特殊事件**：并购、拆分、特别股息可能改变常规的提前行权规律（转述 OIC）

## 6. 管理与退出

止盈目标有一条来源，其余为业界通行做法（推导）：

- **提前止盈**：赚到净权利金的约 50% 就平掉（来源 tastylive「Managing Winning Options Positions」，全文已读：他们的常规做法是赚到最大利润的 50% 平仓，理由是剩余利润变小而风险不变、可更快回收资金；该页未引用任何研究，也未专讲信用价差，属经验主张）。75% 的说法没有找到来源，仅供参考。例子里 50% 即 $60：剩下的收益要拿满额亏损（3.2 倍于满额收益）的风险去换。小额剩余权利金平仓要先算佣金是否划算（同页）
- **止损**（推导，无来源）：常见口径有两种：浮亏达到净权利金的 1~2 倍（例子里 $120~$240）；或股价触及短腿行权价就平。目的是避免吃满额亏损
- **展期**：往后、往上展。但要注意新权利金可能不足以弥补已扩大的亏损，只有"按新行权价我仍愿意开这笔新仓"时才展
- **到期前一两天处理**：股价靠近短腿时，不要留到最后一天猜指派，主动平仓或自己决定如何处理（OIC 的提示）
- **除息日前检查**：只要短腿是实值且外在价值很小，就要查股息日和金额

## 7. 与相邻策略的对比

| 策略 | 相同点 | 不同点 |
|---|---|---|
| **[垂直 Put 贷方价差](bull-put-credit-spread.md)** | 同为收权利金的垂直贷方价差，结构镜像 | 那是看涨，赢的条件是不跌；本页是看跌，赢的条件是不涨。方向不同，风险特征相似：赔率差、需要高胜率 |
| **[Bear Put 借方价差](bear-put-debit-spread.md)** | 同为看跌的有限风险价差 | 那是买入较高行权价 Put、卖出较低行权价 Put，净付钱，靠**下跌**赚；Theta 为负，胜率要求低但要真的跌到位。是同一个看跌观点的另一种拼法 |
| **[备兑 Call](covered-call.md)** | 都是卖 Call 收权利金、收益封顶 | 需要先有 100 股；风险是股价下跌时的股票亏损，对涨的上限也有限。本页不需要股票，但亏损发生在上涨一侧 |
| **[Naked Call](naked-call.md)** | 短腿完全一样 | 没有长腿，理论亏损无限；本页用长腿换了固定最大亏损 |
| **[Iron Condor](iron-condor.md)** | 本页是 Iron Condor 的上半部分 | Iron Condor 上下各一组价差，赌横盘；本页只赌不涨 |

**选择顺序（推导）**：先问"到底是真看跌，还是只是觉得涨不动"——前者可以考虑 [Bear Put 借方价差](bear-put-debit-spread.md)，后者才是本策略；再问"权利金有没有到宽度的 20%"——没到就不如不做。

## 9. 本库工具范围

已有 `/bearcall-sim` 工具可以在模拟盘里记 Call 贷方价差（策略键 `bear_call_spread`，只做模拟，不下单、不连券商），但[公开的模拟盘报告](../paper-trading.md)只覆盖 `bull_put_spread` 和 `cash_secured_put`，**Call 贷方价差一笔都不会出现在上面**，也还没有能下结论的样本。

- **`/strategy-pick` 在"看法=不看好"时推荐这个策略**：未持有（或单账户不足 100 股）时排第二，排在 Bear Put 价差之后；单账户持股 ≥ 100 股时不推荐（持股时推荐减仓和 Bear Put 价差）；热门股财报 7 天内让位给"等财报后再看"。推荐带短 Call Delta 0.10–0.15 的目标，`/bearcall-sim open TICKER --from-pick` 可以直接按它选档；也可以自己给 ticker 手动使用
- 工具的选法（推导，是工具的设计选择，不是来源的结论）：三档按**短腿 Call** 的 Delta 约 0.10 / 0.15 / 0.20，长腿**恰好**在短腿 + 宽度上；到期日取距快照日至少 7 天的第一个；两条腿的买卖价差都必须 ≤ 中间价的 5%
- 记录与统计：一笔记一条整体记录（卖方价差字段 + `option_type: "C"`）；到期每股成本 = clamp(收盘 − 短腿, 0, 宽度)；所需胜率 = 1 − 权利金 ÷ 宽度；不进 Bull Put 的胜率与 Delta 档位表，`/option-journal` 有独立块；30 笔以下不解读
- 每份候选都带两条固定提示：上涨亏钱、最大亏损是宽度减权利金；历史上市场整体向上漂移，看跌样本里亏的概率偏高
- 原因（推导）：本库的核心仍是已有股票时的防守与增强收益，纯做空方向的价差不是交易主线；工具只用来积累样本、对照本页的数字

本页的作用是**知识补全和对照**，帮助理解"Put 贷方价差的镜像"，而不是执行手册。
